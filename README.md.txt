# Sales Dashboard

##  Project Overview
This project is a **Sales & Revenue Analysis Dashboard** created using **Power BI**.  
The dashboard helps analyze sales performance, profit trends, customer insights, and regional sales distribution through interactive visualizations.

---

##  Features
- Interactive Power BI Dashboard
- KPI Cards for:
  - Total Sales
  - Total Profit
  - Total Orders
  - Total Customers
- Sales Trend Analysis
- Category Wise Sales Analysis
- Region Wise Sales Distribution
- Date Filters & Slicers
- Interactive Charts & Visualizations

---

## Dashboard Insights
The dashboard provides:
- Overall business performance overview
- Top-performing categories
- Regional sales comparison
- Sales trends over time
- Customer and order analysis
